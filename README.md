# Landing Page — Sette Lavoro

Arquivos prontos para publicação no GitHub Pages.

## Como atualizar
1. Substitua os arquivos atuais do repositório pelos arquivos desta pasta.
2. Faça Commit no GitHub Desktop.
3. Clique em Push origin.
4. Aguarde alguns minutos para o GitHub Pages atualizar.

## Formulário
O formulário usa FormSubmit e envia para:
contato@settelavoro.com.br

Na primeira submissão, o FormSubmit pode enviar um e-mail de confirmação. É necessário confirmar uma única vez.
